## 一、选品红线（AI自动剔除，命中即跳过，不发布）

出现以下任一类，AI 自动跳过该品、不进入采集、不提交；提交前再复核一遍：

1. **品牌款/侵权**：榜单标题含 Godrej、VANZO、Cmall、ShopWithJoy 等品牌名，或1688结果为品牌贴牌、带Logo授权争议款。
2. **液体/膏体/化工**：洗衣凝珠、洗衣液、精油、香水、胶水液体、香薰液等，物流与合规受限。
3. **电池/带电**：干电池、23A电池、充电电子件、电动奶泡器、定时器等含电池或需插电产品。
4. **食品/保健/医疗**：左旋VC精华片、山楂麦芽茶、食品级直接入口、药品、医疗器械。
5. **宗教/敏感**：宗教用品、民俗祭祀、政治敏感图案。
6. **超重/易碎**：陶瓷碗盘、大体积重物、易碎玻璃，跨境运费与破损风险高。
7. **活物/动植物种苗**。

判定拿不准时（无法排除是否撞红线），**保守跳过、不发布**，记录跳过原因，不转为人工确认。

## 二、AI自动过滤项（不阻断合规，但直接淘汰，不进入打分）

以下由 AI 自动剔除，不保留、不询问：

- **倒挂价**：下游人民币价 `oppRmbPrice` ≤ 1688同款中位价 `matchItmMedPrice`，毛利为负。接口字段是同款**中位价**（非网页"平均售价"），作粗判；正式以页面实际供货价为准。
- **极度拥挤同款**：`matchItmCnt` ≥ 3000，红海竞争，淘汰。
- **平价微利**：下游价/中位价 < 1.10（毛利空间不足10%），淘汰。

### Step1 榜单品打分（AI 取最高分）

通过第一节红线、第二节过滤后，对剩余候选打分，取最高分进入 Step2：

| 维度 | 取值 | 倾向 |
|---|---|---|
| 毛利空间 | `oppRmbPrice / matchItmMedPrice` | 倍数越高越好，优先 ≥1.5 |
| 同款数 | `matchItmCnt` | 100–1500 最佳；过低(供给少)、过高(拥挤)降分 |
| 类目安全 | 三级类目 | 避开液体/带电/食品/易碎等天然高危类目 |
| 排名 | `ranking` | 同分时榜内排名靠前优先 |

无任何候选通过过滤时，换类目/换榜重拉；整榜无合格品则结束，不强行发。

## 三、Step2 AI自动匹配1688现货（接口检索与浏览器结果页通用）

Step2 默认用接口 `search`（关键词）/`search-image`（图搜）取候选，浏览器"找同款"为兜底。两种来源都混入大量无关品（精华片、童装、3D打印配件、牌照架、清洁刷等），AI 按以下顺序自动筛选并选 1 个，不停下询问：

> 接口返回的 `monthSold` 是 **1688 供给侧月销**，用于比较供应商热度，不是 Shopee 销量，不代表下游好卖。

1. **同类硬过滤**：标题/图与榜单品同类（毛巾对毛巾、胶带对胶带），不匹配直接跳过；无关品（车蜡、厨房洗碗布混入擦车巾等）剔除。
2. **资格线**：`compositeScore` ≥ 4.0；月销 `monthSold` 高者优先；源头工厂/现货优先；起订量 `beginQuantity` 低优先。
3. **价格合理**：同款最低价若明显偏离品类区间，不选。
4. **自动取最优**：在合格候选里按月销降序、评分、价格综合打分，自动选 1 个；无合格候选则跳过该榜单品并记录原因，不强行发。
5. 记录标准URL：`https://detail.1688.com/offer/<offerId>.html`。

## 四、结算价模板说明

- 默认模板：`价格 = 来源价 × 130% + 5.00元 − 0.00元`，在ERP内预先配置，批量铺货自动带出，本流程沿用，不每次重算。
- 已知局限（正式放量前再优化，不在铺品现场改）：
  - 固定+5元不随重量变化，重货会亏；
  - 高价品30%比例偏重；
  - 建议按重量分档、设保本地板，并用真实结算账单回填校准。
- 测试阶段重量/尺寸用默认即可，不填写非正式估值。

## 五、发布失败原因归因库

| 失败现象 | 常见原因 | 处理 |
|---|---|---|
| 库存须 0-500000 范围 | 库存数值超界 | 改回"使用商品来源"或重填合法库存 |
| No channel can support the fill in values | 个别站点/渠道不支持该类目或属性 | 单站点失败≠整品失败，记录被拒站点，其余站点成功仍算该品部分成功 |
| 类目/品牌/合规驳回 | 撞红线或品牌 | 剔除该品，勿重复提交 |
| 标题/图片不合规 | 含违禁词、侵权图 | 改标题图后重提 |
| 图像极其有限/比例0.5-32，image_url=cbu01.sorry.com | 采集那一刻抓到1688防盗链/sorry占位域（该域不可解析），非商品问题 | 源站图通常已恢复为正常webp，重新链接采集刷新即可；重采仍sorry则换同款另一offer |
| 404客户端错误: 未找到url cbu01.alicdn.com/...jpg | 1688旧图已删/迁移 | 重新采集取新图；仍404则换同款 |
| 单站点：规格选项名称重复，请使用唯一名称 | 该站点SKU规格名重名 | 仅影响这一个站点，其余成功即整品成功；要补该站点需在编辑里把规格名改唯一后重提 |
| 单站点：get shop available/channels error 10004 | 平台该渠道配置问题，非卖家可修 | 忽略，其余站点成功即整品成功 |

## 六、状态判定速查

- 发布中 / 审核中 / 排队中 = 中间态，**不计成功也不计失败**，等待平台返回。
- 发布成功 = 终态（可多站点分别成功/失败，逐站点记）。
- 发布失败 = 终态，必须抄录失败原因文本。
- 三个指标分开记：采集成功率、提交成功率、最终发布成功率、出单（真实订单），不可互相替代。
