# Shopee Dropship ERP Skill

面向 **Shopee 轻出海** 铺货的 AI Agent 技能（Skill）：从 1688 遨虾（aibuy）Shopee 区域榜单选品 → 点"找同款"挑 1688 现货 → 快递助手 ERP 跨境版链接采集 → 公共采集箱对账 → 批量铺货至 Shopee 轻出海 → 发布记录统计成功/审核中/失败及失败原因。

基于受控浏览器（`aha_browser_use` / `bu`）操作，**不做无头爬虫、不调用未公开 API**。选品匹配、红线判定、登录保留人工确认/接管。

> 说明：Shopee 轻出海是平台代运营、卖家只供货的模式。工具链（选品→采集→铺货）可以跑通，但**铺完 ≠ 快速出单**，出单取决于平台选品与运营；本 Skill 的价值是把供货侧动作标准化并测量发布成功率。

## 适用范围（模式绑定）

**本 Skill 仅适用于一种模式：`快递助手 ERP 跨境版（erp.kuaidizs.cn）+ Shopee 轻出海（平台代运营、卖家供货）`。**

- **适用**：遨虾选品 → 1688 链接采集 → 公共采集箱 → 铺货至 Shopee 轻出海 → 发布记录统计成功率。
- **不适用**（页面/URL/选择器不同会失效，不得直接套用）：
  - 其他 ERP（甩手、芒果店长、店小秘等）；
  - Shopee 自营店铺直接上架（非轻出海代运营模式）；
  - 其他平台铺货（Lazada、TikTok Shop、Amazon 等）。

所有 URL、选择器、结算价模板、成功率口径、失败归因均基于该模式实测；换模式需重做链路适配，不能只改参数。

## 流程（6 步）

1. **遨虾榜单选品**（半自动）：Shopee 海外飙升榜，切国家/类目/翻页，红线筛选后列出候选给用户确认。
2. **找同款取 1688 URL**（半自动）：真实点击"找同款"（`oppItemId` 前端生成，无法预构造 URL），图搜结果噪声大，需人工确认匹配项。
3. **批量链接采集**（自动）：ERP 链接采集页一次粘贴多个 1688 URL，读取成功/失败数。
4. **公共采集箱对账**（自动）：核对条数与货源 ID 与清单一致。
5. **铺货提交**（半自动）：全选 → 勾选轻出海店铺 → 沿用结算价模板（130%+5）→ 提交，提交前人工确认店铺与模板。
6. **发布记录统计**（自动）：按货源 ID 归类 发布中/审核中（中间态）/发布成功/发布失败，抄录失败原因。

## 自动化边界

| 环节 | 方式 |
|---|---|
| 批量采集、对账、全选、提交、统计 | Agent 自动 |
| 图搜挑同款、红线判定、提交前店铺/模板核对 | **人工确认** |
| 登录、短信/验证码 | **人工接管**（`interaction.request_action`） |

## 状态口径（不可混算）

| 状态 | 性质 | 计入成功 |
|---|---|---|
| 发布中 / 审核中 / 排队中 | 中间态 | 否 |
| 发布成功 | 终态 | 是 |
| 发布失败 | 终态 | 否（记录原因） |

- 提交成功率 ≠ 最终发布成功率 ≠ 出单，三个口径分开记录。

## 运行要求

- 受控浏览器环境（`mac_computer_use_tool` + `plane="bu"` + `aha_browser_use`）。
- 已登录快递助手 ERP（登录由用户接管，本 Skill 不含、不请求任何账号凭据）。
- ERP 内已配置结算价模板（默认 `来源价×130% + 5.00 − 0.00`）。

## 已知局限（正式放量前优化）

- 固定 +5 元不随重量变化，重货会亏；高价品 30% 比例偏重。建议按重量分档、设保本地板，并用真实结算账单回填校准。
- 选择器为实测值，页面改版会失效；失效时按 SKILL.md 指引改用文本 `find` 重新定位。
