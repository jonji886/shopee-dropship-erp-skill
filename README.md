# Shopee Dropship ERP Skill

面向 **Shopee 轻出海** 铺货的 AI Agent 技能（Skill）：只读接口拉 1688 遨虾（aibuy）Shopee 区域榜单 → AI 按评分规则自动判定最优商品 → 接口关键词/图搜自动匹配 1688 现货 → 快递助手 ERP 跨境版链接采集 → 公共采集箱对账 → 自动铺货至 Shopee 轻出海 → 发布记录统计成功/审核中/失败及失败原因。

**双通道架构**：
- **Step1/2 取候选（只读接口）**：`scripts/aibuy_rank_client.py` 匿名拉遨虾榜单、检索 1688 现货，导出候选清单；个人只读、低频（≥0.6s 间隔）、不转售；接口无 SLA、前端改版会断，报错即回退浏览器兜底。
- **Step3-6 登录态操作（受控浏览器 `aha_browser_use` / `bu`）**：采集、对账、铺货、统计都在 ERP 登录态内完成，不绕登录、不写账号密码。

> 说明：Shopee 轻出海是平台代运营、卖家只供货的模式。工具链（选品→采集→铺货）可以跑通，但**铺完 ≠ 快速出单**，出单取决于平台选品与运营；本 Skill 的价值是把供货侧动作标准化并测量发布成功率。接口给的是遨虾前端同源快照（无 Shopee 销量/GMV/评分/趋势），1688 月销是供给侧热度，不得据此推断下游好卖。

## 适用范围（模式绑定）

**本 Skill 仅适用于一种模式：`快递助手 ERP 跨境版（erp.kuaidizs.cn）+ Shopee 轻出海（平台代运营、卖家供货）`。**

- **适用**：接口拉遨虾榜单 → AI 自动判定最优 → 接口检索 1688 现货自动匹配 → 1688 链接采集 → 公共采集箱对账 → 自动铺货至 Shopee 轻出海 → 发布记录统计成功率。
- **不适用**（页面/URL/选择器不同会失效，不得直接套用）：
  - 其他 ERP（甩手、芒果店长、店小秘等）；
  - Shopee 自营店铺直接上架（非轻出海代运营模式）；
  - 其他平台铺货（Lazada、TikTok Shop、Amazon 等）。

所有 URL、选择器、结算价模板、成功率口径、失败归因均基于该模式实测；换模式需重做链路适配，不能只改参数。

## 流程（6 步）

1. **接口拉榜单 + AI 判定最优**（全自动）：`aibuy_rank_client.py` 按站点/榜单/类目拉候选，AI 按红线剔除 → 倒挂/拥挤/平价微利过滤 → 毛利空间/同款数/类目安全打分，取最高分进入下一步，不暂停问人。
2. **接口检索 1688 现货 + AI 自动匹配**（全自动）：关键词搜 + 图搜并行取候选，AI 按同类硬过滤 → 评分/月销/起订量资格线 → 自动选 1 个最优 offer；无合格候选跳过并记录原因。接口失效时回退浏览器"找同款"兜底。
3. **批量链接采集**（自动）：ERP 链接采集页一次粘贴多个 1688 URL，读取成功/失败数。
4. **公共采集箱对账**（自动）：核对条数与货源 ID 与清单一致。
5. **自动铺货提交**（全自动）：只勾选本次清单商品（禁止全选历史商品）→ 自动勾选目标店铺（唯一直接勾/多店铺取第一个）→ 沿用结算价模板（130%+5）→ 提交，不暂停确认；仅登录/验证码/支付弹窗转人工接管。
6. **发布记录统计**（自动）：按货源 ID 归类 发布中/审核中（中间态）/发布成功/发布失败，抄录失败原因。

## 自动化边界

| 环节 | 方式 |
|---|---|
| 拉榜单、打分判定、匹配现货、采集、对账、铺货、统计 | **AI 全自动**（不停下问人） |
| 硬红线（品牌侵权/液体化工/带电/食品保健医疗/宗教/易碎/活体） | **AI 自动阻断**，命中或拿不准即跳过不发布 |
| ERP 登录、短信/验证码、支付 | **人工接管**（`interaction.request_action`） |

## 状态口径（不可混算）

| 状态 | 性质 | 计入成功 |
|---|---|---|
| 发布中 / 审核中 / 排队中 | 中间态 | 否 |
| 发布成功 | 终态 | 是 |
| 发布失败 | 终态 | 否（记录原因） |

- 提交成功率 ≠ 最终发布成功率 ≠ 出单，三个口径分开记录。

## 运行要求

- Python 3（纯标准库，无需 pip 安装）。
- 受控浏览器环境（`mac_computer_use_tool` + `plane="bu"` + `aha_browser_use`），Step3-6 使用。
- 已登录快递助手 ERP（登录由用户接管，本 Skill 不含、不请求任何账号凭据）。
- ERP 内已配置结算价模板（默认 `来源价×130% + 5.00 − 0.00`）。

## 已知局限（正式放量前优化）

- 固定 +5 元不随重量变化，重货会亏；高价品 30% 比例偏重。建议按重量分档、设保本地板，并用真实结算账单回填校准。
- 接口为未公开内部 mtop、无 SLA，前端改版会断；报错即回退浏览器兜底，不要反复硬刷。
- 选择器为实测值，页面改版会失效；失效时按 SKILL.md 指引改用文本 `find` 重新定位。
